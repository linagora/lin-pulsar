# 🧭 Migration guide: `0.2.x` → `0.3.0`

Version `0.3.0` renames the library from `linid-catalog-ui` (`catalogUI` remote) to `@linagora/lin-pulsar`
(`LinPulsar` remote), as part of the move from LinID to LinOpenFactory. It also moves from
`@linagora/linid-im-front-corelib` to `@linagora/lin-pulsar-core` `0.1.1`.

All consumers (the host application and every remote) must migrate **at the same time**, since `lin-pulsar-core` is
shared as a strict singleton through Module Federation.

---

## 1. lin-pulsar-core

The host application and every other remote must first migrate to `@linagora/lin-pulsar-core` `0.1.1`, following the
[lin-pulsar-core migration guide](https://github.com/linagora/lin-pulsar-core/blob/main/docs/migrations/0.X.0-0.1.0.md).

---

## 2. Module Federation remote

The remote is renamed from `catalogUI` to `LinPulsar`. Update its declaration in the `remotes` entry of the application
`config.json`:

```diff
 {
-  "name": "catalogUI",
+  "name": "LinPulsar",
   "entry": "http://localhost:5001/mf-manifest.json"
 }
```

Then update every reference to an exposed element in the module and zone configuration files (`remoteName`,
`lifecycleRemote`, `routesRemote`, `i18nRemote`, `layout`, zone `plugin`, ...):

```diff
-"remoteName": "catalogUI",
-"lifecycleRemote": "catalogUI/PageLifecycle",
+"remoteName": "LinPulsar",
+"lifecycleRemote": "LinPulsar/PageLifecycle",
```

The `LinidSmartFilter` exposed component is renamed as well:

| 0.2.x                        | 0.3.0                            |
| ---------------------------- | -------------------------------- |
| `catalogUI/LinidSmartFilter` | `LinPulsar/LinPulsarSmartFilter` |

---

## 3. Smart filter

The smart filter and its internal components are renamed, which changes their translation scopes, design namespaces,
CSS classes and `data-cy` attributes.

| Translation scope (0.2.x) | Translation scope (0.3.0) |
| ------------------------- | ------------------------- |
| `LinidSmartFilter`        | `LinPulsarSmartFilter`    |
| `LinidFilterChip`         | `LinPulsarFilterChip`     |
| `LinidFilterPanel`        | `LinPulsarFilterPanel`    |
| `LinidFavoritePanel`      | `LinPulsarFavoritePanel`  |

| Design namespace (0.2.x) | Design namespace (0.3.0)    |
| ------------------------ | --------------------------- |
| `linid-smart-filter`     | `lin-pulsar-smart-filter`   |
| `linid-filter-chip`      | `lin-pulsar-filter-chip`    |
| `linid-filter-panel`     | `lin-pulsar-filter-panel`   |
| `linid-favorite-panel`   | `lin-pulsar-favorite-panel` |

The CSS classes and `data-cy` attributes follow the same rule: the `linid-` prefix becomes `lin-pulsar-` (e.g.
`linid-smart-filter-field` → `lin-pulsar-smart-filter-field`). Custom styles and end-to-end test selectors must be
updated.

---

## 4. Docker image

The Docker image is published as `linagora/lin-pulsar` instead of `linagora/linid-catalog-ui`.
