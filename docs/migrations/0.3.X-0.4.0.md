# 🧭 Migration guide: `0.3.x` → `0.4.0`

Version `0.4.0` adds the `LinPulsar/LifecyclePanel`, which displays and runs the lifecycle of an entity from its zone
configuration only, and moves the lifecycle actions of the `LifecycleButtonsCard` to it. It requires
`@linagora/lin-pulsar-core` `0.1.7`, which provides `renderJson`.

---

## 1. Lifecycle actions

The `LifecycleButtonsCard` no longer runs actions: its `actions`, `emitOnSubmit`, `immediateActionDelay` and
`triggerActionOn` props are removed, and it only emits `itemClick`. Replace the host component that computed the menu
items and rendered the card by a `LinPulsar/LifecyclePanel` zone entry, which computes the banners, info texts and
dropdowns from the lifecycle state of the entity (see
[LifecyclePanel](../components/panel/LifecyclePanel.md#-lifecycle-state)):

```diff
 {
   "zone": "moduleAccountDetailsPage.content.before",
-  "component": "AccountLifecyclePanel",
+  "plugin": "LinPulsar/LifecyclePanel",
   "props": {
     "immediateActionDelay": 60,
+    "emitOnSubmit": "account-status-updated",
     "actions": { ... }
   }
 }
```

Then update each action:

- Remove `dialog`: an action with `formFields` opens a form dialog, an action without opens a confirmation dialog.
- Read the submitted data from `form` rather than from `entity`, which still holds the entity merged with the form.
- The `body` is now rendered by `renderJson`: a string made of a single `{{ expression }}` keeps the JSON type of its
  value. Use `none` to send `null` for an empty optional field, where the former rendering sent an empty string.

```diff
 "suspension.scheduled": {
-  "dialog": "form",
   "url": "/accounts/{{ entity.id }}/status/suspend",
   "method": "PUT",
   "formFields": [ ... ],
   "body": {
-    "suspensionPeriod": "{{ entity.suspensionPeriod }}",
-    "comment": "{{ entity.statusComment }}"
+    "suspensionPeriod": {
+      "start": "{{ form.suspensionPeriod.start }}",
+      "end": "{{ form.suspensionPeriod.end or none }}"
+    },
+    "comment": "{{ form.statusComment or none }}"
   }
 }
```

## 2. Translations

The translations of the actions move from `[I18N_SCOPE].LifecycleButtonsCard` to `[I18N_SCOPE].LifecyclePanel`, and
the dropdown labels to `[I18N_SCOPE].LifecyclePanel.LifecycleButtonsCard`:

```diff
 {
-  "LifecycleButtonsCard": {
-    "suspension": { "DropdownButton": { "title": "Suspension" } },
-    "actions": { "suspension": { "scheduled": { "FormDialog": { "title": "Schedule the suspension" } } } },
-    "submitSuccess": "Action completed successfully"
-  }
+  "LifecyclePanel": {
+    "LifecycleButtonsCard": {
+      "suspension": { "DropdownButton": { "title": "Suspension" } }
+    },
+    "actions": { "suspension": { "scheduled": { "FormDialog": { "title": "Schedule the suspension" } } } },
+    "submitSuccess": "Action completed successfully"
+  }
 }
```

The default labels shipped by `LinPulsar/DetailsPageI18n` move accordingly, under `{{ config.instanceId }}.LifecyclePanel`.

---

## 3. Design

The dialogs of the actions use the `[UI_NAMESPACE].lifecycle-panel.form-dialog` and
`[UI_NAMESPACE].lifecycle-panel.confirmation-dialog` namespaces, and the dropdowns
`[UI_NAMESPACE].lifecycle-panel.lifecycle-buttons-card` (see [design](../design.md#lifecyclepanel)).
